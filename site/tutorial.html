1. Visão Geral da Pasta /site

A pasta /site abriga todo o front-end web e mobile do cliente Metin2 WebAssembly. Quando você acessa o servidor via navegador, é esta pasta que é servida pelo Nginx. Aqui você pode modificar praticamente tudo na interface visual, adicionar novos recursos, traduzir textos, trocar imagens de carregamento e ajustar o comportamento tátil.

2. Onde estão as Janelas UI e Controles Móveis (mobile_overlay.js)

O arquivo site/mobile_overlay.js é o coração da interface web e mobile. Ele injeta dinamicamente o HUD estilo Dark-Fantasy (Old2) sobre o canvas do jogo quando detecta um dispositivo touch ou modo mobile (?mobile=1).

O que você pode alterar nele:

  • Joystick Virtual & Botões de Movimento: Gerencia o analógico virtual flutuante no lado esquerdo da tela para controle das direções (WASD).
  • Atalhos de Ação Rápida: Botões de ataque físico (Espaço), coleta rápida de itens no chão (Z), poções vermelhas/azuis e atalhos de habilidades (1, 2, 3, 4).
  • Janelas do Jogo (UI): Contém a lógica de abertura e fechamento de janelas essenciais:
    • Inventário (I)
    • Habilidades (K)
    • Janela de Personagem (P)
    • Opções / Configurações (Esc)
  • Histórico de Chat & Caixa de Mensagens: Interface HTML flutuante que exibe as mensagens do chat do jogo em tempo real e permite enviar comandos via bridge Python/WebSocket.
  • Menu Flutuante de Configurações do Jogador:
    • Modo de Desempenho (Eco, Equilibrado, Qualidade)
    • Limite de FPS (30, 60, ilimitado)
    • Vibração tátil (Haptics)
    • Seletor rápido de idiomas (Português, Polonês, Inglês)

3. Tela de Carregamento e Wallpapers (loading/)

O Metin2 Web possui uma recriação fiel da clássica tela de carregamento de 2009 com wallpapers rotativos, barra de progresso autêntica (336x25 pixels) e dicas rotativas.

  • Wallpapers: O script escaneia automaticamente imagens em site/loading/loading0.jpg, loading1.jpg, etc. Para adicionar novos papéis de parede, basta colocar imagens `.jpg` ou `.png` nessa pasta.
  • Barra de Carregamento: As imagens site/loading/gauge_empty.png e site/loading/gauge_full.png definem o visual da barra de progresso.
  • Dicas do Jogo: O array LOADING_TIPS dentro de mobile_overlay.js (ou traduzido via i18n/overlay.json) controla as dicas exibidas na parte inferior durante o carregamento.

4. Traduções, Itens, Habilidades e Mobs (i18n/)

A pasta site/i18n/ contém os dicionários JSON utilizados para traduzir a interface e os dados do jogo para Português, Polonês e Inglês:

  • site/i18n/overlay.json: Textos do HUD, botões do mobile overlay, títulos de janelas e dicas de carregamento.
  • site/i18n/items_i18n.json: Nomes e descrições dos itens do Metin2 em múltiplos idiomas.
  • site/i18n/skills_i18n.json: Nomes das habilidades de todas as classes (Guerreiro, Ninja, Sura, Shaman).
  • site/i18n/mobs_i18n.json: Nomes dos monstros, chefes e NPCs.
  • site/i18n/bonuses_i18n.json: Descrição dos bônus de equipamentos (ex: Força, Vitalidade, Dano de Habilidade, Resistência a Magia).

5. Configurações do Cliente, Desempenho e Canvas (client.html e mobile.html)

  • site/client.html: É a página principal onde o WebAssembly roda. Aqui você encontra:
    • Configurações de WebGL com alta performance (powerPreference: "high-performance").
    • Definições de DPR (PixelRatio) adaptáveis para economizar bateria em celulares ou entregar máxima nitidez no PC.
    • Orçamento de memória para o carregamento dinâmico do corpus (arquivos de assets do jogo divididos em partes).
  • site/mobile.html: Página leve de redirecionamento que detecta dispositivos móveis e inicia o cliente com parâmetros otimizados (buffer interno de 960x540, neblina ajustada, sem sombras pesadas).

6. PWA, Ícones e Service Worker (manifest.json e sw.js)

  • site/manifest.json: Configura o aplicativo como PWA (Progressive Web App). Permite que os jogadores instalem o Metin2 na tela inicial do celular com ícone próprio, cor de tema (#080604) e modo tela cheia.
  • site/sw.js: Service Worker que gerencia o cache offline dos arquivos essenciais, garantindo carregamento ultrarrápido em visitas posteriores.

7. Páginas Extras (Registro, Guerras e Atualizações)

  • site/rejestracja.html: Interface web para criação rápida de contas de jogadores integrada ao banco de dados MariaDB via reg/server.py.
  • site/wojny.html: Central de Guerras de Guildas ao vivo, tabela de classificação e reprodutor de replays 2D/3D.
  • site/aktualizacja.html: Página de notas de atualização e changelog do servidor.

8. Dicas Práticas para Desenvolvedores

Como testar suas alterações:
Sempre que modificar arquivos na pasta /site no seu servidor VPS, limpe o cache do navegador ou abra a página em aba anônima (ou adicione um parâmetro de versão como ?v=999 na URL) para garantir que o navegador baixe os arquivos atualizados.

9. Otimização de Desempenho e Solução de Crashes no Celular

Se o jogo está lento ou fechando (crash) em alguns dispositivos móveis, isso geralmente ocorre por estouro de memória (RAM), sobrecarga da GPU ou superaquecimento. Aqui está como otimizar:

  • Resolução de Renderização: O cliente ajusta a resolução interna baseada no DPR (densidade de pixels) da tela. Use o modo Gráficos: Baixo nas configurações do HUD (ícone de engrenagem) para forçar uma resolução menor, economizando muita RAM e GPU.
  • Limitação de FPS: Jogar com FPS ilimitado em telas de 120Hz drena a bateria e causa superaquecimento. Configure o limite de FPS para 30 ou 45 no menu de configurações do HUD. Isso estabiliza o consumo e evita que o navegador mate o processo.
  • Ocultar Lojas (M1): Em áreas lotadas, o excesso de lojas privadas causa lag. Use os botões "Lojas: Escondidas" ou "Lojas: Perto" no menu de configurações do HUD para reduzir o número de elementos renderizados.
  • Memória RAM (Android/iOS): O cliente utiliza muita RAM para carregar texturas e modelos. O corpusBudget (configurado em client.html) controla o cache de assets. Celulares com menos de 4GB de RAM podem precisar de um ajuste mais conservador neste valor se os crashes persistirem.
